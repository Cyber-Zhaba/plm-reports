# Правила создания отчётов

## Новые отчёты Летучек

1. Создать директорию `letXX/` (например, `let04/`)
2. Скопировать `emblem.png` из `let03/` в новую директорию
3. Создать файл `letXX.typ` по шаблону из `let03/let03.typ`
4. Обновить титульную страницу:
   - `student` - ФИО студента
   - `group` - группа
   - `teacher` - преподаватель
   - `lab_number` - номер лабораторной
   - `course` - название курса
   - `theme` - тема работы
   - `year` - год

## Сборка

```bash
./build.sh
```

Результат собирается в директорию `result/`.

## Обновление flake.nix

Добавить сборку нового отчёта в секцию `buildPhase`:

```nix
typst compile let04/let04.typ let04.pdf
```

Добавить PDF в секцию `installPhase`:

```nix
mv let04.pdf $out/
```

## Обновление build.sh

Не требуется - build.sh автоматически вызывает `nix build`.

## Оформление кода

Использовать функцию `terminal(title: "filename.java")` для блоков кода:

```typst
#terminal(title: "Point.java")[
```java
public class Point {
  ...
}
```
]
```

## Исправление математических формул

Typst не поддерживает `\frac` и `\approx`. Использовать:

- Дроби: `"frac"(x, y)` или текстовое описание
- Приближения: `= 9.81` или текстовое описание
